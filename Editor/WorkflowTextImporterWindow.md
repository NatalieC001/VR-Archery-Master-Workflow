# How to use WorkflowTextImporterWindow

The `WorkflowTextImporterWindow` is a Unity Editor tool designed to help you quickly generate `WorkflowGuideAsset` objects from raw text, such as video transcripts or step-by-step notes. It takes away the pain of manual data entry and provides an AI-friendly format you can copy and use to structure the text properly before importing.

## Getting Started

1. Open Unity.
2. Navigate to **Tools > Workflow Raw Text Importer (Dyslexia-Friendly)** in the top menu bar.

## Using the Importer

1. When the window opens, you will see an **🤖 AI Formatting Prompt Template**.
2. Highlight and copy (`Ctrl+C`) this template.
3. Paste the template into your preferred AI tool (like ChatGPT, Claude, etc.) along with the raw transcript or notes of the tutorial you want to convert.
4. Copy the response generated by the AI.
5. In the `WorkflowTextImporterWindow`, locate the large text area labeled **Paste Raw Text Here**.
6. Paste the AI-formatted text into this area.
7. Fill in the **Guide Metadata** fields:
   * **Guide Title**: A name for your workflow guide.
   * **Creator Name**: The author of the tutorial.
   * **Video Title**: The title of the source video.
   * **Video URL**: The main link to the video.
   * **GitHub Repo URL**: A link to any associated source code repository.
8. Click the large green button **⚡ Generate Workflow Guide Asset**.

## Result

The tool will parse the provided text and metadata, generate a new `WorkflowGuideAsset`, and prompt you to save it in your project. This `.asset` file can then be used with the Generic Workflow Engine (`Tools > Generic Workflow Assistant Window`) to guide you interactively through the tutorial.
